SIR model: from BASIC to Python

This page runs the SIR (susceptible, infected, recovered) program from the BASIC listing below, rewritten in Python. The Python runs right here in your browser, and the table shows whatever the program prints. Edit the code and the table updates; Reset brings back the original program.

The model: each day, susceptible people become infected at a rate of 0.00001 × S × I, and infected people recover at a rate of I / 14 (about a two-week illness). The program uses Euler’s method: it computes the rates, multiplies by the time step deltat, and adds the changes to S, I and R.

NoteOriginal BASIC program 
 1  t = 0
 2  S = 45400
 3  I = 2100
 4  R = 2500
 5  deltat = 1
 6  PRINT t, S, I, R
 7  FOR k = 1 TO 3
 8          Sprime = -.00001 * S * I
 9          Iprime = .00001 * S * I - I / 14
10          Rprime = I / 14
11          deltaS = Sprime * deltat
12          deltaI = Iprime * deltat
13          deltaR = Rprime * deltat
14          t = t + deltat
15          S = S + deltaS
16          I = I + deltaI
17          R = R + deltaR
18          PRINT t, S, I, R
19  NEXT k
